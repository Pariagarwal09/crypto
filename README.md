# CryptoTracker

CryptoTracker is a web-based application that fetches and displays real-time cryptocurrency data.

## Features
- View real-time cryptocurrency prices
- Compare different coins
- Wishlist functionality
- Chart visualization
- Clean user interface

## Tech Stack
- React
- Vite
- JavaScript
- HTML
- CSS

## How to Run
1. Clone the repository
2. Open the project folder
3. Install dependencies using `npm install`
4. Start the project using `npm run dev`

## Purpose
This project was built to practice frontend development, API integration, and React concepts.
